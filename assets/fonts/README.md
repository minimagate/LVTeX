# Fonts

Unmodified files copied from the locally cached `typst-assets` 0.15.1 package:

- `NewCMMath-Regular.otf`: New Computer Modern Math; GUST Font License 1.0
  (LPPL 1.3c or later).
- `LibertinusSerif-Regular.otf`, `LibertinusSerif-Italic.otf`, and `LibertinusSerif-Bold.otf`: Libertinus Serif; SIL Open Font License 1.1.

`UPSTREAM-NOTICE` is the complete unmodified notice from that package. Its first
two sections cover these fonts; later sections concern other upstream assets
that are not copied here. The fonts retain their embedded copyright metadata.

Source: https://github.com/typst/typst-assets/tree/v0.15.1/files/fonts

The renderer embeds the math and regular serif faces; the editor embeds
Libertinus Serif Regular and Italic. The previous Bold face is retained as an unused asset. The
full Typst font bundle is not included.

CormorantGaramond.ttf was downloaded from Google Fonts with its accompanying
CormorantGaramond-OFL.txt license. It is retained as an alternative but is not
linked into the current editor. The user requested a more traditional, readable
serif, so Libertinus Serif is now the editor default.
