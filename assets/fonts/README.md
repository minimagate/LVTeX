# Fonts

Unmodified files copied from the `typst-assets` 0.15.1 package:

- `NewCMMath-Regular.otf`: New Computer Modern Math; GUST Font License 1.0
  (LPPL 1.3c or later). Embedded by the renderer for equations.
- `LibertinusSerif-Regular.otf`: Libertinus Serif; SIL Open Font License 1.1.
  Embedded by the renderer and the editor.
- `LibertinusSerif-Italic.otf`: Libertinus Serif Italic; SIL Open Font License 1.1.
  Embedded by the editor for `# ` titles.

`UPSTREAM-NOTICE` is the complete unmodified notice from that package. Its first
two sections cover these fonts; later sections concern other upstream assets
that are not copied here. The fonts retain their embedded copyright metadata.

Source: https://github.com/typst/typst-assets/tree/v0.15.1/files/fonts
